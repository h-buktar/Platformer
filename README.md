## HOW THIS WAS MADE
I made this using Godot 4.7.2 and wrote scripts using GDScript

## heres how to run the project :)
Clone the source code to your device
```sh
git clone https://github.com/h-buktar/Platformer.git
```
and be joyous!

## Controls for the game

Spacebar => Jump
Left/Right Arrow Keys => Player Movement
